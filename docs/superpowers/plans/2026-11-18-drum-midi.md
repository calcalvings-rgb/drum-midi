# Drum-to-MIDI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python app: input audio (drum stem atau full mix) → detect stem/full → separation (kalau full) → transkripsi percussion → ekspor MIDI GM, kebaca FL Studio piano roll.

**Architecture:** Pipeline stage modular. Tiap stage punya mode (default ringan, tanpa dep ML). GUI tkinter satu window. Backend berat (Demucs/madmom) lazy-install saat pertama dipilih.

**Tech Stack:** Python 3.11+, numpy, scipy (spectral, resample), tkinter (stdlib), stdlib `wave` untuk WAV. Optional lazy: pydub/ffmpeg (decode mp3), demucs, madmom.

**Spec:** `docs/superpowers/specs/2026-11-18-drum-midi-design.md`

## Global Constraints

- Windows box lokal. Default path: nol dep ML, numpy+scipy+stdlib aja.
- Dep berat lazy install, gak pernah di boot.
- Output `.mid` type 1, track per drum, tempo default 120 (param).
- Mapping lewat preset: `maps.py` berisi GM + Mixwave Sleep Token (default user). User bisa pilih/define custom. Mixwave Sleep Token: kick=36, snare=38, side stick=37, rimshot=40, hat closed=75, hat open=46, hat pedal=44, rack1=50, rack2=47, floor=43, crash1=49, crash2=57, ride=51, ride bell=53.
- Gak ada server/daemon, gak ada web UI.

## Review Focus

- File input gak ada / gak bisa dibaca → error jelas, gak crash.
- Audio pendek/kosong → hasil MIDI kosong valid, gak hang.
- Full mix pilih mode separation "none" → tetap transkripsi dari mix asli (boleh kasar).
- Sample rate beda (8k-96k) → resample internal ke 44100 konsisten.
- MIDI note > 127 / velocity di luar 0-127 → clamp.
